# Milestone 3: App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the iced desktop app with everything needed to edit a save end to end:
- the shell: plugin rail, save panel, editor pane, status bar
- the dark amber theme
- Home save discovery with path editing
- detection and open off the UI thread, with a plugin chooser on ties
- the renderer for plugin UI trees, with host-side number buffers and list picks
- Save with backup and atomic write
- the unsaved-changes guard
- crash handling that counts plugin faults
- file logging and a crash report

**Architecture:** New crate `crates/saveforge-app` (lib + `saveforge` bin).
- **Pure helpers** (`format`, `ui_state`, `home`) and the **renderer** (`render`) are tested directly, the renderer through `iced_test`'s headless simulator.
- **Blocking work** (`documents`: detect, open, save) are plain functions that the app runs on tokio's blocking pool. Tests call them directly against the fixture plugin.
- **`App`** is an Elm-style state machine. Tests drive `App::update` with the messages background tasks would produce, and smoke-test `App::view` in the simulator.
- **Plugin calls:** `view`/`update` run synchronously on the UI thread (spec §3.4). `open`/`serialize` run on worker threads; sessions are shared as `Arc<Mutex<DocumentSession>>`.

**Tech Stack:** Rust 1.99 (edition 2024), iced 0.14.0 (`tokio`, `image` features), iced_test 0.14.0, rfd 0.17.2, tokio 1.53.2 (`rt`), time 0.3.55 (`local-offset`), tracing-subscriber 0.3.23, tracing-appender 0.2.5. Existing: `saveforge-core`, `saveforge-host`, `saveforge-plugin-api`.

**Spec:** `docs/superpowers/specs/2026-10-10-rust-iced-rewrite-design.md` (§3.4, §4.5, §5.1, §5.2 Startup/Home/Open/Edit/Save/Unsaved-changes guard, §7, §8 App row)

**Prior milestones:** M1 `saveforge-core` and M2 plugin runtime are merged. The APIs used here:
- `saveforge_host::{PluginEngine, HostLimits, LoadedPlugin, PluginRegistry, PluginEntry, DocumentSession, HostError, Event, UiTree, detect, resolve_aux_files, HEADER_LEN, MAX_FAULTS_PER_SESSION}`
- `saveforge_plugin_api::ui::*`
- `saveforge_core::{discovery::{discover, SaveFileInfo}, settings::AppSettings, paths::AppPaths, tokens::{TokenEnv, Expanded, expand}, backup::save_with_backup, manifest::PluginManifest, platform::Os}`

**Verified draft:** every code block in this plan was compiled, linted (clippy pedantic, `-D warnings`) and tested in a scratch copy of the repo before the plan was written: 168 workspace tests green, `cargo deny` green with the Task 9 config.

## Global Constraints

- **Pinned versions:** `iced = { version = "0.14.0", features = ["tokio", "image"] }`, `iced_test = "0.14.0"`, `rfd = "0.17.2"` (default features: XDG portal, no GTK), `tracing-subscriber = "0.3.23"`, `tracing-appender = "0.2.5"`.
- **Window:** title `SaveForge`, `SaveForge — <file>`, with a ` •` suffix while dirty. Default size 1200×750, minimum 900×600, centered, native decorations. `exit_on_close_request: false`, because the unsaved guard owns closing.
- **Layout:** rail 68 px, save panel 280 px, status bar 28 px. Palette from the .NET `Themes/Colors.axaml`: BG0 `#0B0D14`, BG1 `#12151F`, BG2 `#1A1E2B`, BG3 `#232838`, BG4 `#2D3346`, LINE `#2A3044`, LINE2 `#3A4159`, TEXT `#E6E9F2`, TEXT_DIM `#9AA2B8`, TEXT_FAINT `#5B6276`, AMBER `#F5B942`, GREEN `#6FD479`, RED `#E5484D`.
- **Off the UI thread:** plugin scan, save discovery, detection, open, save all run via `tokio::task::spawn_blocking` inside `Task::perform`. `view`/`update`/`is-dirty` run synchronously on the UI thread.
- **Backups** go to `settings.backup_directory/{plugin-id}/`, through `save_with_backup` (spec §5.2 Save).
- **Plugin faults:** only `HostError::Fault` counts toward disabling. Three faults in a session disable the plugin via `PluginRegistry::record_fault`, and the status bar says so.
- **Logs:** daily rolling `<data_dir>/logs/saveforge.*.log`, 7 files kept. INFO in release, DEBUG plus stderr in debug builds. Panics write `<data_dir>/crash.log`.
- **Local time:** the UTC offset is read once in `run()` before any thread starts (the `time` crate refuses afterwards on Unix), with UTC as the fallback.
- **Deferred:**
  - Store / PluginDetail / Settings / About screens, the update check and the info bar are **Milestone 6**. The rail shows plugin buttons only.
  - Plugin icons render through `iced::widget::image` from `manifest.icon`, falling back to the name's first letter.
- **Tests:** tests live in `crates/saveforge-app/tests/*.rs`. App tests need the fixture: `cargo xtask plugins` first.
- **Lints:** `assert!(x.is_empty())` is rejected by clippy 1.99. Use `assert_eq!`.
- **Branch:** work on `feat/m3-app-shell`, never on `main`.

```rust
//! Display formatting for sizes, dates and the window title.

use std::time::SystemTime;

use time::macros::format_description;
use time::{OffsetDateTime, UtcOffset};

/// `512 B`, `1.5 KB`, `2.0 MB`, `1.2 GB` (1024-based).
pub fn human_size(bytes: u64) -> String {
    const UNITS: [&str; 4] = ["KB", "MB", "GB", "TB"];
    if bytes < 1024 {
        return format!("{bytes} B");
    }
    // Display only: precision loss above 2^53 bytes is irrelevant.
    #[allow(clippy::cast_precision_loss)]
    let mut value = bytes as f64 / 1024.0;
    let mut unit = 0;
    while value >= 1024.0 && unit < UNITS.len() - 1 {
        value /= 1024.0;
        unit += 1;
    }
    format!("{value:.1} {}", UNITS[unit])
}

/// `2026-10-10 14:03` in the given offset.
pub fn format_modified(modified: SystemTime, offset: UtcOffset) -> String {
    OffsetDateTime::from(modified)
        .to_offset(offset)
        .format(format_description!("[year]-[month]-[day] [hour]:[minute]"))
        .unwrap_or_default()
}

/// `SaveForge`, `SaveForge — file.json` or `SaveForge — file.json •` when dirty.
pub fn window_title(file_name: Option<&str>, dirty: bool) -> String {
    match file_name {
        None => "SaveForge".to_owned(),
        Some(name) if dirty => format!("SaveForge — {name} •"),
        Some(name) => format!("SaveForge — {name}"),
    }
}
```

```rust
//! Host-side state the plugin never sees (spec §4.5): the raw text of number
//! fields while the user types, and the pending choice of each list's
//! "Add" pick-list.

use std::collections::{HashMap, HashSet};

use saveforge_plugin_api::ui::{Input, NumberInput, UiTree, Widget};

#[derive(Debug, Clone, Default)]
pub struct UiState {
    numbers: HashMap<String, NumberBuffer>,
    list_choices: HashMap<String, String>,
}

#[derive(Debug, Clone, PartialEq)]
struct NumberBuffer {
    text: String,
    /// The plugin's value when this buffer was written. A different value in a
    /// later tree means the plugin changed it, so the buffer is discarded.
    plugin_value: f64,
    error: Option<String>,
}

/// The plugin's value as the field shows it, with `decimals` places.
pub fn format_number(input: &NumberInput) -> String {
    format!("{:.*}", usize::from(input.decimals), input.value)
}

/// Parses user text against the field's rules. `Err` is the message shown
/// under the field.
pub fn parse_number(text: &str, input: &NumberInput) -> Result<f64, String> {
    let trimmed = text.trim();
    let value = trimmed
        .parse::<f64>()
        .ok()
        .filter(|v| v.is_finite())
        .ok_or_else(|| "Enter a number".to_owned())?;
    let fraction_digits = trimmed.split_once('.').map_or(0, |(_, f)| f.len());
    if fraction_digits > usize::from(input.decimals) {
        return Err(if input.decimals == 0 {
            "Whole numbers only".to_owned()
        } else {
            format!("At most {} decimal places", input.decimals)
        });
    }
    if let Some(min) = input.min
        && value < min
    {
        return Err(format!("Must be at least {min}"));
    }
    if let Some(max) = input.max
        && value > max
    {
        return Err(format!("Must be at most {max}"));
    }
    Ok(value)
}

/// The number input spec of field `id` in `tree`, if any.
pub fn find_number_input<'a>(tree: &'a UiTree, id: &str) -> Option<&'a NumberInput> {
    tree.nodes.iter().find_map(|node| match &node.widget {
        Widget::Field(field) if field.id == id => match &field.input {
            Input::Number(input) => Some(input),
            Input::Text(_) | Input::Checkbox(_) | Input::Pick(_) => None,
        },
        _ => None,
    })
}

impl UiState {
    /// Text and error to show for number field `id`.
    pub fn number_display(&self, id: &str, input: &NumberInput) -> (String, Option<String>) {
        match self.numbers.get(id) {
            Some(buffer) if buffer.plugin_value.to_bits() == input.value.to_bits() => {
                (buffer.text.clone(), buffer.error.clone())
            }
            _ => (format_number(input), None),
        }
    }

    /// Records what the user typed into number field `id`. Returns the value
    /// to send to the plugin when the text is valid.
    pub fn edit_number(&mut self, id: &str, text: String, input: &NumberInput) -> Option<f64> {
        let (plugin_value, error, send) = match parse_number(&text, input) {
            Ok(value) => (value, None, Some(value)),
            Err(error) => (input.value, Some(error), None),
        };
        self.numbers.insert(
            id.to_owned(),
            NumberBuffer {
                text,
                plugin_value,
                error,
            },
        );
        send
    }

    pub fn list_choice(&self, id: &str) -> Option<&str> {
        self.list_choices.get(id).map(String::as_str)
    }

    pub fn set_list_choice(&mut self, id: &str, value: String) {
        self.list_choices.insert(id.to_owned(), value);
    }

    pub fn clear_list_choice(&mut self, id: &str) {
        self.list_choices.remove(id);
    }

    /// Drops state for widgets that are no longer in `tree`.
    pub fn retain(&mut self, tree: &UiTree) {
        let mut numbers = HashSet::new();
        let mut lists = HashSet::new();
        for node in &tree.nodes {
            match &node.widget {
                Widget::Field(field) if matches!(field.input, Input::Number(_)) => {
                    numbers.insert(field.id.as_str());
                }
                Widget::List(list) => {
                    lists.insert(list.id.as_str());
                }
                _ => {}
            }
        }
        self.numbers.retain(|id, _| numbers.contains(id.as_str()));
        self.list_choices
            .retain(|id, _| lists.contains(id.as_str()));
    }
}
```

```rust
//! Renders a plugin's UI tree with iced widgets (spec §4.4, §4.5).
//!
//! The tree has already passed `validate_tree`, so child indices are in range
//! and depth is bounded. `scrollable` nodes are rendered as plain containers:
//! the editor pane already scrolls, and nested vertical scrolling is not
//! supported by iced.

use std::fmt;

use iced::widget::{
    Column, Row, button, checkbox, column, container, pick_list, row, rule, text, text_input,
};
use iced::{Alignment, Element, Length, Theme};
use saveforge_plugin_api::ui::{
    Button as ButtonSpec, ButtonStyle, Event, Field, Input, ListSpec, Node, PickList, PickOption,
    Tabs, TextSpan, TextStyle, UiTree, Widget,
};

use crate::theme;
use crate::ui_state::UiState;

/// What the rendered UI emits. Only `Plugin` events reach the plugin directly;
/// the other two update host-side [`UiState`] first.
#[derive(Debug, Clone, PartialEq)]
pub enum UiMessage {
    Plugin(Event),
    NumberEdited { id: String, text: String },
    ListChoice { id: String, value: String },
}

/// A pick-list option; displays its label, carries its value.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Choice {
    pub value: String,
    pub display: String,
}

impl From<&PickOption> for Choice {
    fn from(option: &PickOption) -> Self {
        Self {
            value: option.value.clone(),
            display: option.display.clone(),
        }
    }
}

impl fmt::Display for Choice {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(&self.display)
    }
}

type ButtonStyleFn = fn(&Theme, button::Status) -> button::Style;

pub fn render<'a>(tree: &'a UiTree, state: &'a UiState) -> Element<'a, UiMessage> {
    node(tree, state, 0)
}

fn node<'a>(tree: &'a UiTree, state: &'a UiState, index: usize) -> Element<'a, UiMessage> {
    let Some(n) = tree.nodes.get(index) else {
        return text("").into();
    };
    let children = || children(tree, state, n);
    match &n.widget {
        Widget::Column => Column::with_children(children()).spacing(8).into(),
        Widget::Row => Row::with_children(children())
            .spacing(8)
            .align_y(Alignment::Center)
            .into(),
        Widget::Scrollable => Column::with_children(children()).into(),
        Widget::Divider => rule::horizontal(1).into(),
        Widget::Section(title) => container(
            column![
                text(title.as_str()).size(15).style(theme::heading),
                Column::with_children(children()).spacing(8),
            ]
            .spacing(8),
        )
        .padding(12)
        .width(Length::Fill)
        .style(theme::section)
        .into(),
        Widget::Tabs(tabs) => tabs_view(tabs, Column::with_children(children()).into()),
        Widget::Text(span) => text_view(span),
        Widget::Field(field) => field_view(field, state),
        Widget::Button(spec) => button_view(spec),
        Widget::List(spec) => list_view(spec, n, tree, state),
    }
}

fn children<'a>(
    tree: &'a UiTree,
    state: &'a UiState,
    n: &'a Node,
) -> impl Iterator<Item = Element<'a, UiMessage>> {
    n.children
        .iter()
        .map(move |&child| node(tree, state, child as usize))
}

fn tabs_view<'a>(tabs: &'a Tabs, page: Element<'a, UiMessage>) -> Element<'a, UiMessage> {
    let strip = Row::with_children(tabs.titles.iter().enumerate().map(|(i, title)| {
        let index = u32::try_from(i).unwrap_or(u32::MAX);
        let style: ButtonStyleFn = if index == tabs.selected {
            button::primary
        } else {
            button::secondary
        };
        button(text(title.as_str()))
            .style(style)
            .on_press(UiMessage::Plugin(Event::TabSelected((
                tabs.id.clone(),
                index,
            ))))
            .into()
    }))
    .spacing(4);
    column![strip, page].spacing(12).into()
}

fn text_view(span: &TextSpan) -> Element<'_, UiMessage> {
    let t = text(span.text.as_str());
    match span.style {
        TextStyle::Body => t.into(),
        TextStyle::Muted => t.style(theme::muted).into(),
        TextStyle::Heading => t.size(18).style(theme::heading).into(),
        TextStyle::Error => t.style(theme::error_text).into(),
    }
}

fn field_view<'a>(field: &'a Field, state: &'a UiState) -> Element<'a, UiMessage> {
    let editable = !field.read_only;
    let (input, buffer_error): (Element<'a, UiMessage>, Option<String>) = match &field.input {
        Input::Text(t) => {
            let id = field.id.clone();
            let max_len = t.max_len;
            let input = text_input(t.placeholder.as_deref().unwrap_or(""), &t.value)
                .on_input_maybe(editable.then_some(move |value: String| {
                    UiMessage::Plugin(Event::TextChanged((id.clone(), clamp_len(value, max_len))))
                }));
            (input.into(), None)
        }
        Input::Number(n) => {
            let (shown, error) = state.number_display(&field.id, n);
            let id = field.id.clone();
            let input =
                text_input("", &shown).on_input_maybe(editable.then_some(move |value: String| {
                    UiMessage::NumberEdited {
                        id: id.clone(),
                        text: value,
                    }
                }));
            (input.into(), error)
        }
        Input::Checkbox(checked) => {
            let id = field.id.clone();
            let input =
                checkbox(*checked).on_toggle_maybe(editable.then_some(move |value: bool| {
                    UiMessage::Plugin(Event::Toggled((id.clone(), value)))
                }));
            (input.into(), None)
        }
        Input::Pick(list) => (pick_view(&field.id, list, editable), None),
    };

    let mut col = column![
        row![
            text(field.label.as_str()).width(Length::Fixed(180.0)),
            container(input).width(Length::Fill),
        ]
        .spacing(12)
        .align_y(Alignment::Center)
    ]
    .spacing(4);
    if let Some(help) = &field.help {
        col = col.push(text(help.as_str()).size(12).style(theme::muted));
    }
    if let Some(error) = field.error.clone().or(buffer_error) {
        col = col.push(text(error).size(12).style(theme::error_text));
    }
    col.into()
}

fn pick_view<'a>(id: &str, list: &'a PickList, editable: bool) -> Element<'a, UiMessage> {
    let options: Vec<Choice> = list.options.iter().map(Choice::from).collect();
    let selected = list
        .selected
        .as_ref()
        .and_then(|value| options.iter().find(|c| &c.value == value).cloned());
    if !editable {
        return text(selected.map(|c| c.display).unwrap_or_default()).into();
    }
    let id = id.to_owned();
    let mut pick = pick_list(options, selected, move |choice: Choice| {
        UiMessage::Plugin(Event::Picked((id.clone(), choice.value)))
    });
    if let Some(placeholder) = &list.placeholder {
        pick = pick.placeholder(placeholder.as_str());
    }
    pick.into()
}

fn button_view(spec: &ButtonSpec) -> Element<'_, UiMessage> {
    let style: ButtonStyleFn = match spec.style {
        ButtonStyle::Primary => button::primary,
        ButtonStyle::Secondary => button::secondary,
        ButtonStyle::Danger => button::danger,
    };
    button(text(spec.label.as_str()))
        .style(style)
        .on_press_maybe(
            spec.enabled
                .then(|| UiMessage::Plugin(Event::Pressed(spec.id.clone()))),
        )
        .into()
}

fn list_view<'a>(
    spec: &'a ListSpec,
    n: &'a Node,
    tree: &'a UiTree,
    state: &'a UiState,
) -> Element<'a, UiMessage> {
    let rows = children(tree, state, n).enumerate().map(|(i, content)| {
        if spec.removable {
            let index = u32::try_from(i).unwrap_or(u32::MAX);
            row![
                container(content).width(Length::Fill),
                button(text("Remove"))
                    .style(button::danger)
                    .on_press(UiMessage::Plugin(Event::ListRemove((
                        spec.id.clone(),
                        index
                    )))),
            ]
            .spacing(8)
            .align_y(Alignment::Center)
            .into()
        } else {
            content
        }
    });
    let mut col = Column::with_children(rows).spacing(6);

    if let Some(options) = &spec.add_options {
        let choices: Vec<Choice> = options.options.iter().map(Choice::from).collect();
        let chosen = state
            .list_choice(&spec.id)
            .and_then(|value| choices.iter().find(|c| c.value == value).cloned());
        let id = spec.id.clone();
        let mut pick = pick_list(choices, chosen.clone(), move |choice: Choice| {
            UiMessage::ListChoice {
                id: id.clone(),
                value: choice.value,
            }
        });
        if let Some(placeholder) = &options.placeholder {
            pick = pick.placeholder(placeholder.as_str());
        }
        let add = button(text("Add")).on_press_maybe(
            chosen.map(|c| UiMessage::Plugin(Event::ListAdd((spec.id.clone(), c.value)))),
        );
        col = col.push(row![pick, add].spacing(8));
    }
    col.into()
}

/// Enforces a text field's `max-len` (in characters) host-side.
fn clamp_len(value: String, max_len: Option<u32>) -> String {
    match max_len.map(|m| m as usize) {
        Some(max) if value.chars().count() > max => value.chars().take(max).collect(),
        _ => value,
    }
}
```

```rust
//! Home screen state: which plugin is selected and where its saves are
//! (spec §5.2 Home).

use std::path::PathBuf;

use saveforge_core::discovery::SaveFileInfo;
use saveforge_core::manifest::PluginManifest;
use saveforge_core::platform::Os;
use saveforge_core::settings::AppSettings;
use saveforge_core::tokens::{Expanded, TokenEnv, expand};

#[derive(Debug, Clone, PartialEq)]
pub enum Saves {
    /// No usable folder; the reason is shown to the user.
    NotConfigured(String),
    Scanning,
    Found(Vec<SaveFileInfo>),
}

#[derive(Debug, Clone, PartialEq)]
pub struct Home {
    pub selected: Option<String>,
    /// The raw (unexpanded) save folder for the selected plugin.
    pub raw_dir: Option<String>,
    pub saves: Saves,
    /// `Some(text)` while the path editor is open.
    pub editing: Option<String>,
}

impl Default for Home {
    fn default() -> Self {
        Self {
            selected: None,
            raw_dir: None,
            saves: Saves::NotConfigured("No plugin selected".to_owned()),
            editing: None,
        }
    }
}

/// The user's override for the plugin, else the manifest default for `os`.
pub fn raw_save_dir(settings: &AppSettings, manifest: &PluginManifest, os: Os) -> Option<String> {
    settings
        .plugin_save_directories
        .get(&manifest.id)
        .cloned()
        .or_else(|| {
            manifest
                .default_save_directories
                .for_os(os)
                .map(str::to_owned)
        })
}

/// An existing directory for `raw`, or the reason it can't be used.
pub fn resolve_save_dir(raw: Option<&str>, env: &TokenEnv) -> Result<PathBuf, String> {
    let raw = raw
        .map(str::trim)
        .filter(|r| !r.is_empty())
        .ok_or_else(|| "No save folder set".to_owned())?;
    match expand(raw, env) {
        Expanded::Unresolved(reason) => Err(reason),
        Expanded::Resolved(path) if path.is_dir() => Ok(path),
        Expanded::Resolved(path) => Err(format!("{} does not exist", path.display())),
    }
}
```

```rust
//! Blocking document operations. The app runs these on worker threads
//! (`spawn_blocking`) so the UI never waits on file I/O or plugin parsing
//! (spec §3.4, §5.2 Open/Save).

use std::fs::File;
use std::io::Read;
use std::path::{Path, PathBuf};
use std::sync::{Arc, Mutex, MutexGuard, PoisonError};

use saveforge_core::backup::save_with_backup;
use saveforge_core::tokens::TokenEnv;
use saveforge_host::{
    DocumentSession, HEADER_LEN, HostError, LoadedPlugin, PluginEngine, PluginRegistry, UiTree,
    detect, resolve_aux_files,
};

/// A failed operation, as shown to the user. `plugin_fault` marks a crash or
/// timeout that counts toward disabling the plugin (spec §7).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Failure {
    pub message: String,
    pub plugin_fault: bool,
}

impl Failure {
    pub fn new(message: impl Into<String>) -> Self {
        Self {
            message: message.into(),
            plugin_fault: false,
        }
    }

    pub fn from_host(error: &HostError) -> Self {
        Self {
            message: error.to_string(),
            plugin_fault: matches!(error, HostError::Fault(_)),
        }
    }
}

#[derive(Debug, Clone)]
pub enum DetectOutcome {
    Open(Arc<LoadedPlugin>),
    /// Several plugins share the top priority; the user picks one.
    Choose(Vec<Arc<LoadedPlugin>>),
    NoMatch,
}

#[derive(Debug, Clone)]
pub struct Detected {
    pub outcome: DetectOutcome,
    /// Ids of plugins whose `detect` crashed or timed out.
    pub faulted: Vec<String>,
}

/// Reads the file's header and asks the matching plugins (spec §5.2 Open).
pub fn detect_file(
    engine: &PluginEngine,
    registry: &PluginRegistry,
    path: &Path,
) -> Result<Detected, Failure> {
    let mut header = Vec::with_capacity(HEADER_LEN);
    File::open(path)
        .and_then(|f| f.take(HEADER_LEN as u64).read_to_end(&mut header))
        .map_err(|e| Failure::new(format!("Could not read {}: {e}", path.display())))?;
    let report = detect(engine, registry, path, &header);
    let faulted = report
        .faults
        .iter()
        .filter(|(_, e)| matches!(e, HostError::Fault(_)))
        .map(|(id, _)| id.clone())
        .collect();
    let outcome = match report.detection {
        saveforge_host::Detection::NoMatch => DetectOutcome::NoMatch,
        saveforge_host::Detection::Winner(plugin) => DetectOutcome::Open(plugin),
        saveforge_host::Detection::Tie(plugins) => DetectOutcome::Choose(plugins),
    };
    Ok(Detected { outcome, faulted })
}

/// A document opened by a plugin, with its first UI tree.
#[derive(Debug, Clone)]
pub struct OpenedDocument {
    pub session: Arc<Mutex<DocumentSession>>,
    pub plugin_id: String,
    pub path: PathBuf,
    pub tree: UiTree,
}

/// Reads the file and its aux files and opens it in `plugin`.
pub fn open_document(
    engine: &PluginEngine,
    plugin: &LoadedPlugin,
    path: &Path,
    tokens: &TokenEnv,
) -> Result<OpenedDocument, Failure> {
    let bytes = std::fs::read(path)
        .map_err(|e| Failure::new(format!("Could not read {}: {e}", path.display())))?;
    let aux = resolve_aux_files(&plugin.manifest, tokens).map_err(|e| Failure::from_host(&e))?;
    let file_name = path
        .file_name()
        .map(|n| n.to_string_lossy().into_owned())
        .unwrap_or_default();
    let mut session = engine
        .open(plugin, &file_name, &bytes, &aux)
        .map_err(|e| Failure::from_host(&e))?;
    let tree = session.view().map_err(|e| Failure::from_host(&e))?;
    Ok(OpenedDocument {
        session: Arc::new(Mutex::new(session)),
        plugin_id: plugin.manifest.id.clone(),
        path: path.to_path_buf(),
        tree,
    })
}

/// Serializes, backs up the original, writes atomically, then tells the
/// plugin the bytes are on disk (spec §5.2 Save). Returns the backup path.
pub fn save_document(
    session: &Mutex<DocumentSession>,
    path: &Path,
    backup_root: &Path,
) -> Result<PathBuf, Failure> {
    let mut session = lock(session);
    let bytes = session.serialize().map_err(|e| Failure::from_host(&e))?;
    let backup = save_with_backup(path, &bytes, backup_root, session.plugin_id())
        .map_err(|e| Failure::new(format!("Save failed: {e}")))?;
    session.mark_saved().map_err(|e| Failure::from_host(&e))?;
    Ok(backup)
}

/// Locks a session; a poisoned lock (a panic while held) still yields the
/// session, whose own poisoning state is authoritative.
pub fn lock(session: &Mutex<DocumentSession>) -> MutexGuard<'_, DocumentSession> {
    session.lock().unwrap_or_else(PoisonError::into_inner)
}
```

```rust
//! The open document: cached UI tree, host-side UI state, dirty and crash
//! state (spec §5.2 Edit).

use std::path::PathBuf;
use std::sync::{Arc, Mutex};

use saveforge_host::{DocumentSession, Event, UiTree};

use crate::documents::{Failure, OpenedDocument, lock};
use crate::render::UiMessage;
use crate::ui_state::{UiState, find_number_input};

#[derive(Debug)]
pub struct Editor {
    pub plugin_id: String,
    pub path: PathBuf,
    session: Arc<Mutex<DocumentSession>>,
    pub tree: UiTree,
    pub ui: UiState,
    pub dirty: bool,
    pub saving: bool,
    /// Set once the plugin crashed; the document can only be closed.
    pub crashed: Option<String>,
}

/// What the app must do after the editor handled a message.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum EditorEffect {
    None,
    /// The plugin crashed or timed out; count it against the plugin.
    PluginFault,
}

impl Editor {
    pub fn new(opened: OpenedDocument) -> Self {
        let mut ui = UiState::default();
        ui.retain(&opened.tree);
        Self {
            plugin_id: opened.plugin_id,
            path: opened.path,
            session: opened.session,
            tree: opened.tree,
            ui,
            dirty: false,
            saving: false,
            crashed: None,
        }
    }

    pub fn session(&self) -> Arc<Mutex<DocumentSession>> {
        Arc::clone(&self.session)
    }

    pub fn file_name(&self) -> String {
        self.path
            .file_name()
            .map(|n| n.to_string_lossy().into_owned())
            .unwrap_or_default()
    }

    /// True when closing would lose work (a crashed document can't be saved).
    pub fn has_unsaved_changes(&self) -> bool {
        self.dirty && self.crashed.is_none()
    }

    /// Applies a renderer message, calling the plugin synchronously
    /// (spec §3.4). Ignored while saving or after a crash.
    pub fn handle(&mut self, message: UiMessage) -> EditorEffect {
        if self.saving || self.crashed.is_some() {
            return EditorEffect::None;
        }
        let event = match message {
            UiMessage::Plugin(Event::ListAdd((id, value))) => {
                self.ui.clear_list_choice(&id);
                Event::ListAdd((id, value))
            }
            UiMessage::Plugin(event) => event,
            UiMessage::ListChoice { id, value } => {
                self.ui.set_list_choice(&id, value);
                return EditorEffect::None;
            }
            UiMessage::NumberEdited { id, text } => {
                let Some(input) = find_number_input(&self.tree, &id).copied() else {
                    return EditorEffect::None;
                };
                match self.ui.edit_number(&id, text, &input) {
                    Some(value) => Event::NumberChanged((id, value)),
                    None => return EditorEffect::None,
                }
            }
        };
        self.dispatch(&event)
    }

    fn dispatch(&mut self, event: &Event) -> EditorEffect {
        let result = {
            let mut session = lock(&self.session);
            session
                .update(event)
                .and_then(|()| session.view())
                .and_then(|tree| session.is_dirty().map(|dirty| (tree, dirty)))
        };
        match result {
            Ok((tree, dirty)) => {
                self.ui.retain(&tree);
                self.tree = tree;
                self.dirty = dirty;
                EditorEffect::None
            }
            Err(error) => self.crash(&Failure::from_host(&error)),
        }
    }

    /// Marks the document crashed. Returns whether it counts as a plugin fault.
    pub fn crash(&mut self, failure: &Failure) -> EditorEffect {
        self.crashed = Some(failure.message.clone());
        self.saving = false;
        if failure.plugin_fault {
            EditorEffect::PluginFault
        } else {
            EditorEffect::None
        }
    }

    pub fn saved(&mut self) {
        self.saving = false;
        self.dirty = false;
    }
}
```

```rust
//! File logging and the crash report (spec §7).

use std::io::Write as _;
use std::path::{Path, PathBuf};

use saveforge_core::paths::AppPaths;
use tracing_appender::non_blocking::WorkerGuard;
use tracing_appender::rolling::{Builder, Rotation};
use tracing_subscriber::filter::LevelFilter;
use tracing_subscriber::fmt;
use tracing_subscriber::prelude::*;

/// Days of daily log files kept in `<data_dir>/logs`.
pub const LOG_DAYS_KEPT: usize = 7;

/// Logs to a daily rolling file (and stderr in debug builds). Keep the
/// returned guard alive for the life of the process so buffered lines flush.
pub fn init(paths: &AppPaths) -> Option<WorkerGuard> {
    let level = if cfg!(debug_assertions) {
        LevelFilter::DEBUG
    } else {
        LevelFilter::INFO
    };
    let appender = Builder::new()
        .rotation(Rotation::DAILY)
        .filename_prefix("saveforge")
        .filename_suffix("log")
        .max_log_files(LOG_DAYS_KEPT)
        .build(paths.logs_dir());
    let (file_layer, guard) = match appender {
        Ok(appender) => {
            let (writer, guard) = tracing_appender::non_blocking(appender);
            (
                Some(fmt::layer().with_writer(writer).with_ansi(false)),
                Some(guard),
            )
        }
        Err(e) => {
            eprintln!("logging to file disabled: {e}");
            (None, None)
        }
    };
    let stderr_layer = cfg!(debug_assertions).then(|| fmt::layer().with_writer(std::io::stderr));
    let _ = tracing_subscriber::registry()
        .with(level)
        .with(file_layer)
        .with(stderr_layer)
        .try_init();
    guard
}

/// Writes `crash.log` on panic, then runs the default hook. With
/// `panic = "abort"` in release builds this is the last code that runs.
pub fn install_panic_hook(crash_log: PathBuf) {
    let previous = std::panic::take_hook();
    std::panic::set_hook(Box::new(move |info| {
        let report = format!(
            "{info}\n\nbacktrace:\n{}",
            std::backtrace::Backtrace::force_capture()
        );
        if let Err(e) = write_crash_report(&crash_log, &report) {
            eprintln!("could not write crash report: {e}");
        }
        tracing::error!("panic: {info}");
        previous(info);
    }));
}

/// Replaces `path` with `report`, creating parent directories.
pub fn write_crash_report(path: &Path, report: &str) -> std::io::Result<()> {
    if let Some(parent) = path.parent() {
        std::fs::create_dir_all(parent)?;
    }
    let mut file = std::fs::File::create(path)?;
    writeln!(file, "SaveForge {} crashed.", env!("CARGO_PKG_VERSION"))?;
    file.write_all(report.as_bytes())
}
```

```rust
    SelectPlugin(String),
    CloseEditor,
    Exit(window::Id),
}

#[derive(Debug, Clone)]
pub enum Modal {

        path: PathBuf,
        candidates: Vec<Arc<LoadedPlugin>>,
    },
    Unsaved {
        then: Pending,
    },
}

#[derive(Debug, Clone)]
pub enum Message {
    PluginsLoaded(PluginRegistry),
    SelectPlugin(String),
    SavesFound {
        plugin_id: String,
        saves: Vec<SaveFileInfo>,
    },
    RefreshSaves,
    EditPath,
    PathChanged(String),
    BrowsePath,
    PathBrowsed(Option<PathBuf>),
    ConfirmPath,
    CancelPath,
    OpenSave(PathBuf),
    Detected {
        path: PathBuf,
        result: Result<Detected, Failure>,
    },
    ChoosePlugin {
        path: PathBuf,
        plugin_id: String,
    },
    Opened {
        plugin_id: String,
        result: Result<OpenedDocument, Failure>,

#[derive(Debug)]
pub struct App {
    services: Option<Services>,
    fatal: Option<String>,
    settings: AppSettings,
    plugins: Plugins,
    home: Home,
    editor: Option<Editor>,
    modal: Option<Modal>,
    status: Option<String>,
    busy: Option<String>,
    after_save: Option<Pending>,

impl App {
    /// Starts with plugins loading in the background (spec §5.2 Startup).
    pub fn new(
        services: Services,
        settings: AppSettings,
        warning: Option<String>,
    ) -> (Self, Task<Message>) {
        let engine = Arc::clone(&services.engine);
        let plugin_dir = settings.plugin_directory.clone();
        let app = Self {
            services: Some(services),
            fatal: None,
            settings,
            plugins: Plugins::Loading,
            home: Home::default(),
            editor: None,
            modal: None,
            status: warning,
            busy: Some("Loading plugins…".to_owned()),
            after_save: None,
        };
        let task = blocking(
            move || PluginRegistry::scan(&engine, &plugin_dir),
            Message::PluginsLoaded,
        );
        (app, task)
    }

    /// An app that can only show why it could not start.
    pub fn failed(reason: String, settings: AppSettings) -> Self {
        Self {
            services: None,
            fatal: Some(reason),
            settings,
            plugins: Plugins::Ready(PluginRegistry::default()),
            home: Home::default(),
            editor: None,
            modal: None,
            status: None,
            busy: None,
            after_save: None,
        }
    }

    pub fn title(&self) -> String {
        window_title(
            self.editor.as_ref().map(Editor::file_name).as_deref(),
            self.editor.as_ref().is_some_and(|e| e.dirty),
        )
    }

    pub fn home(&self) -> &Home {
        &self.home
    }

    pub fn editor(&self) -> Option<&Editor> {
        self.editor.as_ref()
    }

    pub fn modal(&self) -> Option<&Modal> {
        self.modal.as_ref()
    }

    pub fn status(&self) -> Option<&str> {
        self.status.as_deref()
    }

    pub fn busy(&self) -> Option<&str> {
        self.busy.as_deref()
    }

    pub fn settings(&self) -> &AppSettings {
        &self.settings
    }

    pub fn registry(&self) -> Option<&PluginRegistry> {
        match &self.plugins {
            Plugins::Ready(registry) => Some(registry),
            Plugins::Loading => None,
        }
    }

    pub fn subscription(&self) -> Subscription<Message> {
        Subscription::batch([
            window::close_requests().map(Message::CloseRequested),
            keyboard::listen().filter_map(|event| match event {
                keyboard::Event::KeyPressed { key, modifiers, .. }
                    if modifiers.command() && key == keyboard::Key::Character("s".into()) =>
                {
                    Some(Message::Save)
                }
                _ => None,
            }),
        ])
    }

    #[allow(clippy::too_many_lines)] // one arm per message keeps the flow readable
    pub fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::PluginsLoaded(registry) => {
                self.busy = None;
                let first = registry.loaded().next().map(|p| p.manifest.id.clone());
                self.plugins = Plugins::Ready(registry);
                first.map_or_else(Task::none, |id| self.select_plugin(id))
            }
            Message::SelectPlugin(id) => {
                if self.home.selected.as_deref() == Some(id.as_str()) {
                    return Task::none();
                }
                self.guarded(Pending::SelectPlugin(id))
            }
            Message::SavesFound { plugin_id, saves } => {
                if self.home.selected.as_deref() == Some(plugin_id.as_str()) {
                    self.home.saves = Saves::Found(saves);
                }
                Task::none()
            }
            Message::RefreshSaves => self.scan_saves(),
            Message::EditPath => {
                self.home.editing = Some(self.home.raw_dir.clone().unwrap_or_default());
                Task::none()
            }
            Message::PathChanged(text) => {
                if self.home.editing.is_some() {
                    self.home.editing = Some(text);
                }
                Task::none()
            }
            Message::BrowsePath => Task::perform(
                async {
                    rfd::AsyncFileDialog::new()
                        .pick_folder()
                        .await
                        .map(|handle| handle.path().to_path_buf())
                },
                Message::PathBrowsed,
            ),
            Message::PathBrowsed(Some(path)) => {
                self.home.editing = Some(path.display().to_string());
                Task::none()
            }
            Message::PathBrowsed(None) => Task::none(),
            Message::ConfirmPath => self.confirm_path(),
            Message::CancelPath => {
                self.home.editing = None;
                Task::none()
            }
            Message::OpenSave(path) => self.guarded(Pending::OpenFile(path)),
            Message::Detected { path, result } => self.detected(path, result),
            Message::ChoosePlugin { path, plugin_id } => {
                self.modal = None;
                match self.loaded_plugin(&plugin_id) {
                    Some(plugin) => self.start_open(plugin, path),
                    None => Task::none(),
                }
            }
            Message::Opened { plugin_id, result } => {
                self.busy = None;
                match result {
                    Ok(opened) => {
                        self.status = None;
                        self.editor = Some(Editor::new(opened));
                    }
                    Err(failure) => {
                        self.status = Some(failure.message.clone());
                        if failure.plugin_fault {
                            self.record_fault(&plugin_id);
                        }
                    }
                }
                Task::none()
            }
            Message::Editor(ui) => {
                let effect = self.editor.as_mut().map(|editor| editor.handle(ui));
                if effect == Some(EditorEffect::PluginFault)
                    && let Some(id) = self.editor.as_ref().map(|e| e.plugin_id.clone())
                {
                    self.record_fault(&id);
                }
                Task::none()
            }
            Message::Save => self.start_save(),
            Message::Saved(result) => self.saved(result),
            Message::CloseEditor => self.guarded(Pending::CloseEditor),
            Message::GuardSave => {
                if let Some(Modal::Unsaved { then }) = self.modal.take() {
                    self.after_save = Some(then);
                    return self.start_save();
                }
                Task::none()
            }
            Message::GuardDiscard => match self.modal.take() {
                Some(Modal::Unsaved { then }) => self.perform(then),
                other => {
                    self.modal = other;
                    Task::none()
                }
            },
            Message::CancelModal => {
                self.modal = None;
                self.after_save = None;
                Task::none()
            }
            Message::CloseRequested(id) => self.guarded(Pending::Exit(id)),
        }
    }

    /// Runs `action` now, or asks first when the editor has unsaved changes.
    fn guarded(&mut self, action: Pending) -> Task<Message> {
        if self
            .editor
            .as_ref()
            .is_some_and(Editor::has_unsaved_changes)
        {
            self.modal = Some(Modal::Unsaved { then: action });
            Task::none()
        } else {
            self.perform(action)
        }
    }

    fn perform(&mut self, action: Pending) -> Task<Message> {
        match action {
            Pending::OpenFile(path) => {
                self.editor = None;
                self.start_detect(path)
            }
            Pending::SelectPlugin(id) => self.select_plugin(id),
            Pending::CloseEditor => {
                self.editor = None;
                Task::none()
            }
            Pending::Exit(id) => window::close(id),
        }
    }

    fn select_plugin(&mut self, id: String) -> Task<Message> {
        self.editor = None;
        self.home.editing = None;
        self.home.raw_dir = self
            .loaded_plugin(&id)
            .and_then(|p| raw_save_dir(&self.settings, &p.manifest, Os::current()));
        self.home.selected = Some(id);
        self.scan_saves()
    }

    fn scan_saves(&mut self) -> Task<Message> {
        let (Some(services), Some(id)) = (&self.services, self.home.selected.clone()) else {
            return Task::none();
        };
        let Some(plugin) = self.loaded_plugin(&id) else {
            return Task::none();
        };
        match resolve_save_dir(self.home.raw_dir.as_deref(), &services.tokens) {
            Err(reason) => {
                self.home.saves = Saves::NotConfigured(reason);
                Task::none()
            }
            Ok(dir) => {
                self.home.saves = Saves::Scanning;
                let extensions = plugin.manifest.file_extensions.clone();
                blocking(
                    move || discover(&dir, &extensions),
                    move |saves| Message::SavesFound {
                        plugin_id: id.clone(),
                        saves,
                    },
                )
            }
        }
    }

    fn confirm_path(&mut self) -> Task<Message> {
        let (Some(raw), Some(id)) = (self.home.editing.take(), self.home.selected.clone()) else {
            return Task::none();
        };
        let raw = raw.trim().to_owned();
        self.settings
            .plugin_save_directories
            .insert(id, raw.clone());
        if let Some(services) = &self.services
            && let Err(e) = self.settings.save(&services.paths.settings_file())
        {
            tracing::warn!(error = %e, "could not save settings");
            self.status = Some(format!("Could not save settings: {e}"));
        }
        self.home.raw_dir = Some(raw);
        self.scan_saves()
    }

    fn start_detect(&mut self, path: PathBuf) -> Task<Message> {
        let (Some(services), Plugins::Ready(registry)) = (&self.services, &self.plugins) else {
            return Task::none();
        };
        self.busy = Some("Detecting…".to_owned());
        let engine = Arc::clone(&services.engine);
        let registry = registry.clone();
        let target = path.clone();
        blocking(
            move || detect_file(&engine, &registry, &target),
            move |result| Message::Detected {
                path: path.clone(),
                result,
            },
        )
    }

    fn detected(&mut self, path: PathBuf, result: Result<Detected, Failure>) -> Task<Message> {
        self.busy = None;
        let detected = match result {
            Ok(detected) => detected,
            Err(failure) => {
                self.status = Some(failure.message);
                return Task::none();
            }
        };
        for id in &detected.faulted {
            self.record_fault(id);
        }
        match detected.outcome {
            DetectOutcome::Open(plugin) => self.start_open(plugin, path),
            DetectOutcome::Choose(candidates) => {
                self.modal = Some(Modal::ChoosePlugin { path, candidates });
                Task::none()
            }
            DetectOutcome::NoMatch => {
                let name = path
                    .file_name()
                    .map(|n| n.to_string_lossy().into_owned())
                    .unwrap_or_default();
                self.status = Some(format!("No plugin can open {name}"));
                Task::none()
            }
        }
    }

    fn start_open(&mut self, plugin: Arc<LoadedPlugin>, path: PathBuf) -> Task<Message> {
        let Some(services) = &self.services else {
            return Task::none();
        };
        self.busy = Some(format!("Opening with {}…", plugin.manifest.name));
        let engine = Arc::clone(&services.engine);
        let tokens = Arc::clone(&services.tokens);
        let plugin_id = plugin.manifest.id.clone();
        blocking(
            move || open_document(&engine, &plugin, &path, &tokens),
            move |result| Message::Opened {
                plugin_id: plugin_id.clone(),
                result,
            },
        )
    }

    fn start_save(&mut self) -> Task<Message> {
        let Some(editor) = self.editor.as_mut() else {
            return Task::none();
        };
        if editor.saving || editor.crashed.is_some() {
            return Task::none();
        }
        editor.saving = true;
        self.busy = Some("Saving…".to_owned());
        let session = editor.session();
        let path = editor.path.clone();
        let backup_root = self.settings.backup_directory.clone();
        blocking(
            move || save_document(&session, &path, &backup_root),
            Message::Saved,
        )
    }

    fn saved(&mut self, result: Result<PathBuf, Failure>) -> Task<Message> {
        self.busy = None;
        let after = self.after_save.take();
        let Some(editor) = self.editor.as_mut() else {
            return Task::none();
        };
        match result {
            Ok(backup) => {
                editor.saved();
                self.status = Some(format!("Saved. Backup: {}", backup.display()));
                // The file's size and modified time changed: refresh the list.
                let rescan = self.scan_saves();
                let then = after.map_or_else(Task::none, |pending| self.perform(pending));
                Task::batch([rescan, then])
            }
            Err(failure) => {
                editor.saving = false;
                self.status = Some(failure.message.clone());
                if failure.plugin_fault {
                    editor.crash(&failure);
                    let id = editor.plugin_id.clone();
                    self.record_fault(&id);
                }
                Task::none()
            }
        }
    }

    fn loaded_plugin(&self, id: &str) -> Option<Arc<LoadedPlugin>> {
        match self.registry()?.get(id)? {
            PluginEntry::Loaded(plugin) => Some(Arc::clone(plugin)),
            PluginEntry::Failed { .. } => None,
        }
    }

    fn record_fault(&mut self, id: &str) {
        if let Plugins::Ready(registry) = &mut self.plugins
            && registry.record_fault(id)
        {
            self.status = Some(format!(
                "Plugin '{id}' was disabled after repeated crashes. Restart SaveForge to re-enable it."
            ));
        }
    }
}

/// Runs `work` on tokio's blocking pool and maps its result to a message.
fn blocking<T: Send + 'static>(
    work: impl FnOnce() -> T + Send + 'static,
    to_message: impl Fn(T) -> Message + Send + 'static,
) -> Task<Message> {
    Task::perform(
        async move {
            tokio::task::spawn_blocking(work)
                .await
                .expect("blocking task panicked")
        },
        to_message,
    )
}

/// Builds the app's services and runs the iced event loop.
pub fn run() -> iced::Result {
    // Must happen before any thread starts: `time` refuses to read the local
    // offset on Unix once the process is multi-threaded.
    let local_offset = UtcOffset::current_local_offset().unwrap_or(UtcOffset::UTC);
    let paths = AppPaths::detect()
        .unwrap_or_else(|| AppPaths::under(std::env::temp_dir().join("SaveForge")));
    let _log_guard = crate::logging::init(&paths);
    crate::logging::install_panic_hook(paths.crash_log());
    let loaded = AppSettings::load(&paths.settings_file(), AppSettings::defaults(&paths));
    let settings = loaded.settings;
    let warning = loaded.warning;

    iced::application(
        move || boot(&paths, settings.clone(), warning.clone(), local_offset),
        App::update,
        App::view,
    )
    .title(App::title)
    .theme(|_: &App| crate::theme::theme())
    .subscription(App::subscription)
    .window(window::Settings {
        size: iced::Size::new(1200.0, 750.0),
        min_size: Some(iced::Size::new(900.0, 600.0)),
        position: window::Position::Centered,
        exit_on_close_request: false,
        ..window::Settings::default()
    })
    .run()
}

fn boot(
    paths: &AppPaths,
    settings: AppSettings,
    warning: Option<String>,
    local_offset: UtcOffset,
) -> (App, Task<Message>) {
    let cache = paths.wasm_cache_dir();
    match PluginEngine::new(saveforge_host::HostLimits::default(), Some(&cache)) {
        Ok(engine) => App::new(
            Services {
                engine: Arc::new(engine),
                paths: paths.clone(),
                tokens: Arc::new(TokenEnv::detect()),
                local_offset,
            },
            settings,
            warning,
        ),
        Err(e) => {
            tracing::error!(error = %e, "plugin engine failed to start");
            (
                App::failed(format!("SaveForge could not start: {e}"), settings),
                Task::none(),
            )
        }
    }
}
```

```rust
//! The shell layout (spec §5.1): rail, save panel, main pane, status bar and
//! modals.

use iced::widget::{
    Column, button, center, column, container, image, opaque, row, scrollable, space, stack, text,
    text_input, tooltip,
};
use iced::{Alignment, Element, Length};
use saveforge_host::PluginEntry;
use time::UtcOffset;

use super::{App, Message, Modal, Pending, Plugins};
use crate::format::{format_modified, human_size};
use crate::home::{Saves, resolve_save_dir};
use crate::render::render;
use crate::theme;

impl App {
    pub fn view(&self) -> Element<'_, Message> {
        let page = column![
            row![self.rail(), self.save_panel(), self.main_pane()].height(Length::Fill),
            self.status_bar(),
        ];
        match &self.modal {
            Some(modal) => stack![
                page,
                opaque(
                    center(self.modal_view(modal))
                        .style(theme::backdrop)
                        .width(Length::Fill)
                        .height(Length::Fill)
                ),
            ]
            .into(),
            None => page.into(),
        }
    }

    fn rail(&self) -> Element<'_, Message> {
        let buttons: Vec<Element<'_, Message>> = match &self.plugins {
            Plugins::Loading => vec![text("…").into()],
            Plugins::Ready(registry) => registry
                .entries()
                .iter()
                .map(|entry| self.rail_button(entry))
                .collect(),
        };
        container(
            Column::with_children(buttons)
                .spacing(8)
                .align_x(Alignment::Center),
        )
        .padding([12, 0])
        .width(Length::Fixed(theme::RAIL_WIDTH))
        .height(Length::Fill)
        .align_x(Alignment::Center)
        .style(theme::rail)
        .into()
    }

    fn rail_button<'a>(&'a self, entry: &'a PluginEntry) -> Element<'a, Message> {
        let id = entry.id();
        let selected = self.home.selected.as_deref() == Some(id);
        let (face, tip, on_press): (Element<'a, Message>, String, Option<Message>) = match entry {
            PluginEntry::Loaded(plugin) => {
                let face = match &plugin.manifest.icon {
                    Some(icon) => image(image::Handle::from_path(plugin.dir.join(icon)))
                        .width(28)
                        .height(28)
                        .into(),
                    None => initial(&plugin.manifest.name),
                };
                let tip = if selected {
                    format!("{} — {}", plugin.manifest.name, self.save_summary())
                } else {
                    plugin.manifest.name.clone()
                };
                (face, tip, Some(Message::SelectPlugin(id.to_owned())))
            }
            PluginEntry::Failed { reason, .. } => {
                (initial(id), format!("{id}: load failed — {reason}"), None)
            }
        };
        let button = button(center(face))
            .width(40)
            .height(40)
            .padding(0)
            .style(theme::rail_button(selected))
            .on_press_maybe(on_press);
        tooltip(button, text(tip), tooltip::Position::Right).into()
    }

    fn save_summary(&self) -> String {
        match &self.home.saves {
            Saves::NotConfigured(_) => "path not set".to_owned(),
            Saves::Scanning => "scanning…".to_owned(),
            Saves::Found(saves) if saves.len() == 1 => "1 save".to_owned(),
            Saves::Found(saves) => format!("{} saves", saves.len()),
        }
    }

    fn save_panel(&self) -> Element<'_, Message> {
        container(scrollable(self.save_panel_body().padding(12)))
            .width(Length::Fixed(theme::PANEL_WIDTH))
            .height(Length::Fill)
            .style(theme::panel)
            .into()
    }

    fn save_panel_body(&self) -> Column<'_, Message> {
        let registry = match &self.plugins {
            Plugins::Loading => return column![text("Loading plugins…").style(theme::muted)],
            Plugins::Ready(registry) => registry,
        };
        let Some(plugin) = self
            .home
            .selected
            .as_deref()
            .and_then(|id| registry.get(id))
            .and_then(|entry| match entry {
                PluginEntry::Loaded(plugin) => Some(plugin),
                PluginEntry::Failed { .. } => None,
            })
        else {
            return column![
                text("No plugins installed").size(16),
                text(format!(
                    "Plugins are loaded from {}",
                    self.settings.plugin_directory.display()
                ))
                .size(12)
                .style(theme::muted),
            ]
            .spacing(8);
        };

        let mut col = column![text(plugin.manifest.name.as_str()).size(16)].spacing(10);
        if let Some(editing) = &self.home.editing {
            return col.push(self.path_editor(editing));
        }
        col = col.push(
            row![
                text(self.home.raw_dir.as_deref().unwrap_or("No folder set"))
                    .size(12)
                    .style(theme::muted)
                    .width(Length::Fill),
                button(text("Edit").size(12)).on_press(Message::EditPath),
            ]
            .spacing(6)
            .align_y(Alignment::Center),
        );
        match &self.home.saves {
            Saves::NotConfigured(reason) => col
                .push(text("No save folder").size(15))
                .push(text(reason.as_str()).size(12).style(theme::muted))
                .push(button("Set path").on_press(Message::EditPath)),
            Saves::Scanning => col.push(text("Scanning…").style(theme::muted)),
            Saves::Found(saves) if saves.is_empty() => col
                .push(text("No saves found").style(theme::muted))
                .push(button(text("Refresh").size(12)).on_press(Message::RefreshSaves)),
            Saves::Found(saves) => {
                let offset = self
                    .services
                    .as_ref()
                    .map_or(UtcOffset::UTC, |s| s.local_offset);
                let open_path = self.editor.as_ref().map(|e| &e.path);
                col = col.push(
                    row![
                        text(self.save_summary())
                            .size(12)
                            .style(theme::muted)
                            .width(Length::Fill),
                        button(text("Refresh").size(12)).on_press(Message::RefreshSaves),
                    ]
                    .align_y(Alignment::Center),
                );
                col.extend(saves.iter().map(|save| {
                    button(
                        column![
                            text(save.file_name.as_str()),
                            text(format!(
                                "{} · {}",
                                format_modified(save.modified, offset),
                                human_size(save.size_bytes)
                            ))
                            .size(12)
                            .style(theme::muted),
                        ]
                        .spacing(2),
                    )
                    .width(Length::Fill)
                    .style(theme::save_row(open_path == Some(&save.path)))
                    .on_press(Message::OpenSave(save.path.clone()))
                    .into()
                }))
            }
        }
    }

    fn path_editor<'a>(&'a self, editing: &'a str) -> Element<'a, Message> {
        let hint = match &self.services {
            Some(services) => match resolve_save_dir(Some(editing), &services.tokens) {
                Ok(path) => text(format!("→ {}", path.display())).style(theme::muted),
                Err(reason) => text(reason).style(theme::error_text),
            },
            None => text(""),
        };
        column![
            text_input("%APPDATA%/Game/Saves", editing)
                .on_input(Message::PathChanged)
                .on_submit(Message::ConfirmPath),
            row![
                button(text("Browse…").size(12)).on_press(Message::BrowsePath),
                space::horizontal(),
                button(text("Cancel").size(12))
                    .style(button::secondary)
                    .on_press(Message::CancelPath),
                button(text("Save path").size(12)).on_press(Message::ConfirmPath),
            ]
            .spacing(6),
            hint.size(12),
        ]
        .spacing(8)
        .into()
    }

    fn main_pane(&self) -> Element<'_, Message> {
        let content: Element<'_, Message> = if let Some(reason) = &self.fatal {
            center(text(reason.as_str()).style(theme::error_text)).into()
        } else if let Some(editor) = &self.editor {
            if let Some(reason) = &editor.crashed {
                center(
                    column![
                        text("The plugin crashed").size(18),
                        text(reason.as_str()).style(theme::error_text),
                        text("The file on disk was not changed.").style(theme::muted),
                        button("Back").on_press(Message::CloseEditor),
                    ]
                    .spacing(10)
                    .align_x(Alignment::Center),
                )
                .into()
            } else {
                let save = button("Save").on_press_maybe((!editor.saving).then_some(Message::Save));
                column![
                    row![
                        text(editor.file_name()).size(16),
                        text(if editor.dirty { "•" } else { "" }).style(theme::heading),
                        space::horizontal(),
                        save,
                        button("Close")
                            .style(button::secondary)
                            .on_press(Message::CloseEditor),
                    ]
                    .spacing(8)
                    .align_y(Alignment::Center),
                    scrollable(
                        container(render(&editor.tree, &editor.ui).map(Message::Editor))
                            .padding([0, 16])
                    )
                    .height(Length::Fill),
                ]
                .spacing(12)
                .into()
            }
        } else if let Some(busy) = &self.busy {
            center(text(busy.as_str()).style(theme::muted)).into()
        } else {
            center(text("Select a save on the left to edit it.").style(theme::muted)).into()
        };
        container(content)
            .padding(16)
            .width(Length::Fill)
            .height(Length::Fill)
            .into()
    }

    fn status_bar(&self) -> Element<'_, Message> {
        let message = self
            .busy
            .as_deref()
            .filter(|_| self.editor.is_some())
            .or(self.status.as_deref())
            .unwrap_or("");
        container(text(message).size(12))
            .padding([6, 12])
            .width(Length::Fill)
            .height(Length::Fixed(theme::STATUS_HEIGHT))
            .style(theme::status_bar)
            .into()
    }

    fn modal_view<'a>(&'a self, modal: &'a Modal) -> Element<'a, Message> {
        let body: Column<'a, Message> = match modal {
            Modal::ChoosePlugin { path, candidates } => {
                let name = path
                    .file_name()
                    .map(|n| n.to_string_lossy().into_owned())
                    .unwrap_or_default();
                let mut col = column![
                    text("Choose a plugin").size(18),
                    text(format!("Several plugins can open {name}.")).style(theme::muted),
                ]
                .spacing(10);
                col = col.extend(candidates.iter().map(|plugin| {
                    button(text(plugin.manifest.name.as_str()))
                        .width(Length::Fill)
                        .on_press(Message::ChoosePlugin {
                            path: path.clone(),
                            plugin_id: plugin.manifest.id.clone(),
                        })
                        .into()
                }));
                col.push(
                    button("Cancel")
                        .style(button::secondary)
                        .on_press(Message::CancelModal),
                )
            }
            Modal::Unsaved { then } => {
                let file = self
                    .editor
                    .as_ref()
                    .map(super::Editor::file_name)
                    .unwrap_or_default();
                let action = match then {
                    Pending::Exit(_) => "quitting",
                    Pending::OpenFile(_) => "opening another file",
                    Pending::SelectPlugin(_) => "switching plugin",
                    Pending::CloseEditor => "closing",
                };
                column![
                    text("Unsaved changes").size(18),
                    text(format!("Save changes to {file} before {action}?")),
                    row![
                        button("Save").on_press(Message::GuardSave),
                        button("Discard")
                            .style(button::danger)
                            .on_press(Message::GuardDiscard),
                        button("Cancel")
                            .style(button::secondary)
                            .on_press(Message::CancelModal),
                    ]
                    .spacing(8),
                ]
                .spacing(12)
            }
        };
        container(body)
            .padding(20)
            .max_width(420)
            .style(theme::modal)
            .into()
    }
}

/// A plugin's first letter, used when it ships no icon.
fn initial<'a>(name: &str) -> Element<'a, Message> {
    let letter: String = name
        .chars()
        .next()
        .map(|c| c.to_uppercase().collect())
        .unwrap_or_default();
    text(letter).size(18).into()
}
```
